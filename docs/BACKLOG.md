# Бэклог фич

Делать по порядку, каждый тикет — отдельная итерация (отдельный чат с ИИ или отдельный
коммит). Полная архитектура — в `CLAUDE.md` и в
`/Users/garfield/.claude/plans/merry-hugging-kahn.md`. Идеи, которые ещё не стали
тикетами, — в [IDEAS.md](IDEAS.md). Исследования — в [research/](research/).

## MVP-скоуп

Цель MVP — начать реально пользоваться ботом (фото еды → КБЖУ → дневной итог) как можно
быстрее. Всё остальное (нормы КБЖУ по формуле, коррекция оценок текстом, трекинг веса,
cron-отчёты/напоминания, Docker-деплой) — отдельные тикеты после MVP, добавляются по
одному, когда основной цикл уже проверен на себе.

**В MVP входят (в этом порядке):** 1 (упрощённая схема), 2, 4, 5 (упрощённая, только
кнопка "Удалить"), 6, 8 (упрощённый, без сравнения с нормой).
**В MVP НЕ входят:** 3, 7, 9, 10, 11, 12, 13, 14, 15, 16, 17 — помечены как "Пост-MVP" ниже.
Бот на этапе MVP запускается локально через `npm run dev` (long polling, публичный
сервер не нужен) — Docker/VPS нужен только когда ботом начнут пользоваться реальные
друзья/семья постоянно.

## 19. Первый вход и анкета (P0: 1–3) — ГОТОВО
- [x] `/start` без кода (и другие команды) у нового пользователя — приветствие (что
      умеет бот) + «пришлите инвайт-код», а не «Неверный код». Deep link
      `t.me/<bot>?start=<код>` — код из payload погашается сразу (`parseGuestInput` в
      `accessGate.ts`).
- [x] `/start` у пользователя с профилем — «С возвращением» и главное меню, без анкеты;
      без профиля (после удаления) — анкета.
- [x] Анкета: посторонний ввод не теряется молча — подсказка «выберите кнопкой / введите
      число», в первой анкете команды и меню — «сначала закончите анкету»; ответы на
      вопросы с выбором текстом («мужской», «хочу похудеть», номер варианта —
      `matchChoiceText`; при отрицании или нескольких подходящих вариантах не угадывает,
      просит выбрать кнопкой), число со словами вокруг («175 см», «мне 30» —
      `parseNumberText`, им же теперь пользуются `/weight` и `/workout`);
      «◀️ Назад» на каждом вопросе, кроме первого; прогресс «(2/7)»; у отвеченного
      вопроса убираются кнопки и дописывается ответ. Повторная анкета (профиль уже есть)

## 32. Одна кнопка «💬 Поправить или спросить» вместо «✏️ Изменить» и «💬 Обсудить с Ням-Ням» — ГОТОВО

пересматриваются (хватает записанного состава). Отвергнуто: одна кнопка с выбором
«поправить / спросить» (выбор остаётся, на тап дальше) и просто переименование (кнопок
по-прежнему две). Миграция не нужна; тренировки (`✏️ Изменить` у них) — вне скоупа.
