# Бэклог фич

Делать по порядку, каждый тикет — отдельная итерация (отдельный чат с ИИ или отдельный
коммит). Полная архитектура — в `CLAUDE.md` и в
`/Users/garfield/.claude/plans/merry-hugging-kahn.md`.

## MVP-скоуп

Цель MVP — начать реально пользоваться ботом (фото еды → КБЖУ → дневной итог) как можно
быстрее. Всё остальное (нормы КБЖУ по формуле, коррекция оценок текстом, трекинг веса,
cron-отчёты/напоминания, Docker-деплой) — отдельные тикеты после MVP, добавляются по
одному, когда основной цикл уже проверен на себе.

**В MVP входят (в этом порядке):** 1 (упрощённая схема), 2, 4, 5 (упрощённая, только
кнопка "Удалить"), 6, 8 (упрощённый, без сравнения с нормой).
**В MVP НЕ входят:** 3, 7, 9, 10, 11, 12, 13, 14, 15, 16, 17 — помечены как "Пост-MVP" ниже.
Бот на этапе MVP запускается локально через `npm run dev` (long polling, публичный
сервер не нужен) — Docker/VPS нужен только когда ботом начнут пользоваться реальные
друзья/семья постоянно.

## 17. Личный коуч «Ням-Ням» — Пост-MVP — ГОТОВО

практики и психолог пищевого поведения в одном лице. Отвечает с опорой на данные
пользователя (профиль, BMR/TDEE, норма, дневник питания, вес).
- [x] Контракт `src/ai/coach.ts` (`askCoach`, `commentOnPeriod`, `CoachDataSource`),
      реализация `src/claude/coach.ts` — tool use только на чтение
      (`get_daily_summaries` ≤ 31 дня, `get_meal_items`, `get_weight_history`), до 5
      раундов инструментов.
- [x] Кнопка «🐱 Спросить Ням-Ням» → режим разговора: текст и голос идут коучу, фото
      по-прежнему пишутся в дневник. Выход — «✖️ Завершить разговор» или `/exit`.
- [x] Память — только в рамках сессии, в памяти процесса: до 20 реплик, час
      бездействия, фоновая очистка раз в 10 минут (`src/features/coach/session.ts`).
- [x] Длинных ответов не бывает: `max_tokens` 700/250, обрезка по последнему
      предложению при `max_tokens`, жёсткий потолок 4000 символов.
- [x] Комментарий Ням-Ням в вечерней сводке и недельном отчёте (тикет 12), кнопка
      «💬 Обсудить с Ням-Ням» открывает разговор с текстом отчёта в контексте.
- Идеи на потом: «🍽 Что съесть?» под остаток нормы; фото с вопросом «можно мне это?»
  без записи в дневник; инструменты на запись («запиши вес 78»); заметки о
  пользователе (аллергии, предпочтения); напоминания (тикет 13) голосом Ням-Ням;
  мини-челленджи; дневной лимит вопросов на пользователя.
